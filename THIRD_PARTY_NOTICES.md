This repository uses embedded IOP modules and libraries from PS2SDK under
their respective upstream licenses. The `ps2hdd-sparse-skip.irx` module is a
project build of the PS2SDK HDD driver with the slow sparse free-space wipe
disabled.

The runtime package contains compiled third-party PS2 homebrew applications:

- wLaunchELF R3Z/DS34
- Open PS2 Loader
- PadTest
- POPSLoader

These applications are not authored by RepairBox.pl. Their names, code and
binaries remain subject to the licenses and terms of their respective
projects. Packaging an application for PSX XMB does not change its original
license.

in this repository or embedded in the installer ELF.
