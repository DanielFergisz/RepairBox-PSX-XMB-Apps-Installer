# Changelog

## v1.0

- Hardware-verified installation on PSX1 and PSX2.
- Automatic hardware revision detection from `__system/version.txt`.
- Installs wLaunchELF, Open PS2 Loader, PadTest and POPSLoader in fixed XMB
  slots.
- Reinstallation updates or repairs existing slots without adding duplicate
  XMB entries.
- Source and target SHA-256 verification for every runtime package file.
